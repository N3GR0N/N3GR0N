## 🚀 Proyectos destacados

### 🔭 [AetherScope](https://aether-scope-two.vercel.app/) · Deep Space Spectral Navigator

Visualizador y analizador del espacio profundo sobre un lienzo celeste interactivo, alimentado con datos reales de telescopios espaciales (**JWST, Hubble, Chandra y Gaia**) a través de surveys HiPS/CDS/ESA.

- Exploración del cielo con **Aladin Lite**, análisis de sectores y laboratorio con bitácora de misión
- Interfaz estilo *bento* con paleta propia y tipografía monoespaciada
- Desplegado en **Vercel** con **Supabase**, con monitoreo de disponibilidad

`Next.js` `React` `Tailwind CSS` `Aladin Lite` `Supabase` `Vercel`

[🌐 Ver demo](https://aether-scope-two.vercel.app/)

### ☀️ FlareField

Aplicación de alertas de clima espacial pensada para trabajadores rurales de Argentina. Combina datos de **NASA DONKI** y **NOAA** sobre un mapa interactivo, con una interfaz oscura de superficies tipo *glass*.

`Next.js (App Router)` `MapLibre` `Tailwind CSS` `Framer Motion`
